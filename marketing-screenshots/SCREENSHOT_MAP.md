## Screenshot Inventory

### 01-HERO-dashboard-overview.png
**Landing Page Section:** Hero Section / Main Product Showcase
**What it shows:** Full dashboard with 6 widget cards - Files (active cases), My Tasks (kanban queue), Diary (AI-powered calendar), Documents (latest updates), Case Analytics (donut chart), Client Analytics. Shows the sidebar navigation and "Space cadet" law firm name.
**Selling point:** "Your entire practice at a glance" - the command center for a modern law firm.
**v0 usage:** Use as the main hero mockup image, slightly tilted with a subtle shadow. This is the first thing visitors see.

## v0 Prompt Tip

When referencing these in your v0 prompt, tell v0:
> "Use placeholder mockup images styled as browser windows showing a dark-themed legal SaaS dashboard. The screenshots show: [describe each one]. Style them with rounded corners, subtle drop shadows, and a slight 3D tilt for the hero section."

Since v0 can't use actual screenshots, describe what each one shows so v0 generates matching placeholder mockups.
